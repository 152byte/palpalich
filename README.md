# 🎬 Портфолио видеографа

Персональный сайт-портфолио для видеомонтажера и видеографа. Демонстрирует работы в различных категориях, процесс обработки видео (До/После) и предоставляет контакты для связи.

🔗 **Сайт в сети:** [https://152byte.github.io/palpalich/](https://152byte.github.io/palpalich/) 

---

## ✨ Возможности

* 🌐 **Мультиязычность:** Полная поддержка русского и английского языков с выбором при первом входе.
*  **Категоризированное портфолио:** Разделы Experts, Motion, Vlog, Travel и Gaming.
* 🔄 **Слайдеры "До / После":** Интерактивное сравнение исходников и финального монтажа.
* ✨ **Анимированный фон:** Интерактивные частицы на Canvas API, реагирующие на курсор.
*  **Адаптивность:** Полностью отзывчивый дизайн для мобильных устройств, планшетов и десктопов.
* 🚀 **Автогенерация контента:** Python-скрипт автоматически сканирует папки с видео и обновляет список на сайте.
* 🎨 **Темная тема:** Стильный минималистичный дизайн с красно-белыми акцентами.

---

## 🛠 Технологии

* **Frontend:** HTML5, CSS3 (Flexbox, Grid, CSS Variables), Vanilla JavaScript (ES6+)
* **Графика:** HTML5 Canvas API (для фона), SVG (иконки)
* **Backend/Утилиты:** Python 3 (для генерации JSON-списка видео)
* **Хостинг:** GitHub Pages
