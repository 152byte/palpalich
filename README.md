## 🎬 Как добавить новые видео

### Шаг 1: Положить файл в нужную папку

| Категория         | Папка           | Формат              |
|-------------------|-----------------|---------------------|
| Reels             | `videos/reels/` | Вертикальный 9:16   |
| Экспертные Reels  | `videos/expert/`| Вертикальный 9:16   |
| Игровые           | `videos/gaming/`| Горизонтальный 16:9 |

Имя файла станет названием работы

### Шаг 2: Запустить скрипт обновления

```bash
python update_videos.py
